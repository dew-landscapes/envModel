# Iteratively add trees to random forest

Trees are added until predictions stabilise or a maximum number of trees
is reached.

## Usage

``` r
run_iterative_rf(
  env_df,
  clust_col = "cluster",
  env_names,
  trees_start = 499,
  trees_add = 249,
  trees_max = 9999,
  rf_cores = 1,
  use_mtry = NULL,
  set_min = FALSE,
  stopping_metric = "changed_pred",
  stopping_delta = 0.005,
  stopping_runs = 3,
  test_data = FALSE,
  do_imp = FALSE,
  keep_rf = FALSE,
  out_file = NULL,
  force_new = FALSE,
  verbose = base::interactive(),
  ...
)
```

## Arguments

- env_df:

  Dataframe with `clust_col`, `site_col` and columns `env_names`.

- clust_col:

  Character. Name of the columns with clusters.

- env_names:

  Character. Name of the environmental variables (e.g.
  `names(stack_list)`).

- trees_start:

  Number of trees in first random forest run.

- trees_add:

  Number of trees to add in each subsequent run.

- trees_max:

  Maximum number of trees in the random forest.

- rf_cores:

  Number of cores to use for parallel processing.

- use_mtry:

  `mtry` value for
  [`randomForest::randomForest()`](https://rdrr.io/pkg/randomForest/man/randomForest.html)
  call. If `NULL` it will be generated by a (lengthy) call to
  [`caret::train()`](https://rdrr.io/pkg/caret/man/train.html) with a
  tune grid of `.mtry = 1:floor(sqrt(length(env_names))`.

- set_min:

  FALSE or numeric. If numeric, classes in `clust_col` with less than
  `set_min` rows will be filtered

- stopping_metric:

  Character. Either "changed_pred" (proportion of predictions that
  change between runs) or any metric returned by a summary of
  [`yardstick::conf_mat()`](https://yardstick.tidymodels.org/reference/conf_mat.html)

- stopping_delta:

  What proportion change between runs is acceptable?

- stopping_runs:

  How many runs (in a row) need to beat `stopping_delta`?

- test_data:

  Either `FALSE` to test against the training data, or new data in same
  format as `env_df`, against which to calculate metrics.

- do_imp:

  Logical. Passed to `importance` argument of
  [`randomForest::randomForest()`](https://rdrr.io/pkg/randomForest/man/randomForest.html).

- keep_rf:

  Logical. If true, `randomForest` object will be included in output.
  Defaults to `FALSE` to save memory.

- out_file:

  Optional name (and path) of file to save results

- force_new:

  Logical. If `out_file` already exists, should that file be loaded
  (`FALSE`) or run again (`TRUE`) from scratch (and written over).

- ...:

  Passed (via `make_rf_quick()`) to
  [`randomForest::randomForest()`](https://rdrr.io/pkg/randomForest/man/randomForest.html).
